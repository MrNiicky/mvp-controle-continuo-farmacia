# FarmaCare MVP — Controle de Uso Contínuo e Acompanhamento Comunitário

Aplicação Web Responsiva desenvolvida como Produto Mínimo Viável (MVP) para a **Drogaria São Lucas**, alinhada ao **ODS 3 (Saúde e Bem-Estar)** da ONU.

## 🎯 Problema Resolvido
Substituição do controle manual em cadernos de papel por um sistema ágil de balcão que:
- Cadastra pacientes de uso contínuo (hipertensos, diabéticos, etc.).
- Calcula automaticamente a data prevista de término do medicamento e vencimento da receita.
- Exibe alertas prioritários com atalho direto para envio de lembrete via WhatsApp Web.
- Mantém histórico cronológico de aferições de pressão arterial e glicemia capilar.

## 🛠️ Tecnologias
- HTML5, CSS3 e JavaScript (Vanilla / Node.js para testes)
- Testes Automatizados: Jest / Node Test Runner
- Integração Contínua (CI): GitHub Actions
